# v2 — the design-diversity engine

> The release that makes the variety claim *scalable*: a much larger combinatorial design space, per-slide layout generation, charts, a real editor, and PDF export.

## What this release is

v1 proved the flow with a curated 10–15 family registry and human review. v2 makes the design system a real *engine*:

- The design space grows to 30+ families and per-slide layout **generation** (the model designs new layouts within the family's grammar, not just picks from a catalogue)
- Charts become first-class
- A **real editor** arrives (the retention loop): change copy, reorder slides, re-skin, with undo/redo
- **PDF export** joins the single-file HTML
- An automated **vision critic** joins human review (bounded, one revision)
- A **fingerprint metric** gates the acceptance run (the variety claim measured, not vibes)
