# v3 — the business

> The release that turns the generator into a product people pay for: accounts, the hosted URL, brand kit at scale, team collaboration, billing, and publishing.

## What this release is

v1 proved the flow. v2 proved the variety scales. v3 proves the product can be a *business*: a marketer can sign up, keep a brand kit, collaborate with a team, publish a deck to a hosted URL (with the single-file HTML still downloadable), and be billed. It also adds the security that multi-tenancy demands — auth, RLS, quotas — and, only if the market asks, native PPTX export.
