# Demo script — 3 minutes (2026-10-10)

The live link: https://web-production-41f09.up.railway.app. Sign in before going on stage.

**The rule:** never wait on a model live. A deck takes 4–8 minutes to build. Start one at the beginning so it runs in the background, and show finished decks for everything else.

## Before going on stage

1. Sign in. Open **Your decks** (`/decks`) in tab 1.
2. Open the showcase decks below in tabs 2–4, each in present mode (**Present**).
3. Check the day's spend cap still has room: one live deck costs about $0.70, and the cap is $5.
4. Have one screenshot of your product ready on the desktop (for the screenshot step).

| Tab | Deck | Why it is there |

| 3 | Brewly (Soft) `3674023c7de3` | Cream and green, real numbers with sources: the "says something" claim |
| 4 | d-design project deck `9eccf47871f8` | A college project deck with the real product screenshot |

## The click path

| Time | Do | Say |
|---|---|---|
| 0:00 | Home page. Type: *"Launch deck for Tessel 2, a note-taking app that now works offline"*. Leave Kind on **Any kind**, then **Start**. | "Gamma gives you a template. We give every deck its own designer." |
| 0:20 | Questions page: answer two questions, add one screenshot under **Your screenshots**. | "It interviews you first, so the numbers are yours, not invented." |
| 0:40 | Outline page: point at a fact with its source, then approve it and **Build**. Leave it running. | "Every number traces to you or a cited source. Anything else is flagged." |
| 0:55 | Switch to tab 2 (Swarvani) and step through 4 slides. | "The model writes real HTML and CSS inside a design system made for this deck. Nothing here is a template." |
| 1:30 | Tab 3 (Brewly): a chart slide, then the sources. | "Every slide is rendered in Chromium and measured before you see it. Text that overflows or clashes gets repaired." |
| 2:00 | Tab 1 → open Brewly → **Edit** → **The deck** → **Ask for the whole deck**: *"More breathing room"*. | "One instruction redesigns every slide. One undo puts it back." |
| 2:30 | **Export** → **Download to send**. Open the file with Wi-Fi off. | "One HTML file, zero network requests. It works on a plane." |
| 2:50 | Back to the live build from 0:40, if it has finished. | "And that's the one we started three minutes ago." |

## If something goes wrong

- **The live build is slow or fails:** don't wait for it. Say it is still building and stay on the showcase decks.
- **A slide is flagged:** say "it measured a problem and told you instead of hiding it". That is the point of the QA step.
- **The site does not load:** present the offline `.html` exports of tabs 2–3 from the desktop. Download them before going on stage.
